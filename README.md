# Web Application Security Assessment using Burp Suite and Host Header Injection Testing

## Project Overview

Conducted a web application security assessment in a controlled lab environment using Burp Suite. The project focused on capturing HTTP requests, analyzing web traffic, testing Host Header Injection vulnerabilities, assessing password reset functionality, identifying security risks, and documenting mitigation recommendations.

## Objectives

- Understand web application request and response handling
- Capture and analyze HTTP traffic using Burp Suite
- Identify Host Header Injection vulnerabilities
- Assess password reset functionality security
- Demonstrate exploitation within an authorized lab environment
- Analyze security risks associated with Host Header Injection
- Recommend mitigation and security controls
- Document findings and testing results

## Tools & Technologies Used

- Kali Linux
- Burp Suite Community Edition
- Burp Proxy
- Burp Repeater
- HTTP Request Analysis
- Web Application Security Testing
- Packet Capture and Traffic Analysis
- PortSwigger Web Security Academy Labs

## What Was Done

- Configured Burp Suite proxy for web traffic interception
- Captured HTTP requests and responses
- Analyzed application request structure and headers
- Identified Host Header handling mechanisms
- Intercepted password reset requests
- Modified Host header values using Burp Repeater
- Tested Host Header Injection scenarios
- Verified application acceptance of modified Host headers
- Observed manipulated password reset links
- Demonstrated impact of Host Header Injection in a lab environment
- Assessed potential account takeover risks
- Documented security findings and exploitation workflow
- Reviewed mitigation strategies and best practices
- Produced a comprehensive security assessment report

## Outcome

Successfully performed a web application security assessment using Burp Suite and demonstrated Host Header Injection within an authorized lab environment. The project improved understanding of web application security testing, HTTP request manipulation, vulnerability assessment methodologies, and secure application design principles.
